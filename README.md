# Safe Space

Native Android Safe Space wellbeing prototype.

Current build: **v1.6.0**

The home dashboard includes mood check-in, companion, journal, relax, insights, support, Play & unwind, and a counsellor support section. The counsellor area links to Find a Counsellor, Book a Session, Chat Now, and Request Callback prototype flows and supports light/dark system themes.

## Build

```bash
./gradlew :app:assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`
